# NoodleAI Web v0.7 — Studio UI

Visual redesign only. BLE, dataset, training, INT8 quantization, threshold sweep,
NAI4 packaging, deployment, and inference JavaScript logic are unchanged from
Mode 2 Web v0.6.

Highlights:
- new NoodleAI Studio visual identity
- dark embedded-lab shell with high-contrast work panels
- compact hardware/device status strip
- clearer dataset/train workflow
- stronger model diagnostics presentation
- dedicated on-device inference card
- responsive laptop/tablet/mobile layout

All existing DOM IDs used by `js/app.js`, `js/ble.js`, and `js/core.js` are
preserved.
